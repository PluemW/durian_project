# Robot World 
This is part of simulation to set the environment and parameter for simulating.

## Setting up world
World can be able to set and apply by [durian_world.sdf](https://github.com/PluemW/durian_project/blob/main/dev_ws/src/robot_world/world/durian_world.sdf) file, especially adjust sensor and testing moving pattern.

This part had been called by [robot_simulation](https://github.com/PluemW/durian_project/tree/main/dev_ws/src/robot_simulation) in launch file.
